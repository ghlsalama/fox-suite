# Fox Suite — Master Go-to-Market Plan

## Week 1: Deploy + Launch

### Day 1-2: Deploy all 3 products
1. Create Supabase project "fox-suite"
2. Run all 3 schema.sql files
3. Deploy ReplyFox to Render
4. Deploy PostPilot to Render  
5. Deploy DescFox to Render
6. Create Stripe products (3 individual + 1 bundle)
7. Set up webhooks

### Day 3: Product Hunt Launch
- Launch the Fox Suite bundle (not individual products)
- Title: "Fox Suite — 3 AI Tools for Your Business, $59/month"
- Post in: r/SideProject, r/SaaS, r/smallbusiness, IndieHackers
- Email 20 supporters the night before

### Day 4-7: Cold Outreach Blitz
- 50 emails/day for 4 days = 200 prospects
- ReplyFox: target websites with no chatbot
- PostPilot: target businesses with inactive social
- DescFox: target Amazon/Shopify sellers
- Goal: 10 signups

## Week 2-4: Content + Community

### SEO Content (automated by fleet blog)
- "AI customer support for small business"
- "How to write Amazon product descriptions"
- "Social media content ideas for [industry]"
- "AI tools for e-commerce sellers"

### Community Engagement
- Post genuinely helpful advice in r/AmazonSeller, r/Shopify, r/smallbusiness
- Answer questions on Quora/IndieHackers
- Join 5 relevant Discord/Slack communities

### Affiliate Program Launch
- 30% recurring commission
- Recruit 10 early affiliates from communities
- Provide them with demo links + assets

## Month 2-3: Optimize + Scale

### Analyze
- Which product converts best? → double down on outreach for that one
- What's the most common customer question? → add to FAQ/landing
- What's the churn reason? → fix the product gap

### Expand Distribution
- Shopify App Store listing (ReplyFox + DescFox)
- WordPress plugin (ReplyFox widget)
- Chrome extension (DescFox — write on Amazon Seller Central directly)

### Paid Acquisition (when MRR > $2,000)
- Google Ads: "AI chatbot for website" / "product description generator"
- Facebook Ads: targeting small business owners
- Budget: 20% of MRR reinvested
